# MOUTHY AI Beta — Upload Tonight

## What's included
- Unified chat-first UI with no mode picker.
- Selected custom MOUTHY AI icon in favicon, Apple touch icon, and PWA sizes.
- Customization panel for bot name, personality, avatar preview, and extra instructions.
- First-login introduction for new users.
- Distinct vulgar/funny welcome for beta testers.
- Distinct sassy, vulgar creator welcome for the owner email configured in the prototype.
- Local demo replies, local chat history, and preview-only owner dashboard.

## Publish using GitHub Pages
1. Extract this ZIP.
2. Upload the **contents** of the extracted folder to the root of your repository, preserving `assets/`, `index.html`, and `manifest.webmanifest`.
3. Go to **Settings → Pages**.
4. Choose deployment from the `main` branch and `/ (root)`.
5. Open the published site and use Safari **Share → Add to Home Screen** to test the app icon.

## Critical prototype limitations
This is a front-end prototype. Replies are canned demo responses, not a connected AI model. The email-based owner check is not secure authentication. The owner welcome depends on the email typed into this demo and can be impersonated. Founder approvals, transfers, and introductions are local browser data, not secure account records. Before inviting testers to rely on accounts or entitlements, add secure authentication, server-side authorization, a real AI backend, and server-side profile storage.
